# 重電業會有哪些文件、什麼格式——為「換一種文件類型重走流程」做的推測

2026-10-30，mini。目的：下一個實驗要換掉法規公報，換成「重電業（變壓器、開關設備、配電盤這類製造商）實際會有的文件」。公開資料找不到任何一家的內部文件，這頁是**從公開的採購制度、施工規範、監察報告反推**出來的清單，每一條標「查到的」或「推測的」。沒有點名任何公司。

## 1. 文件家族（照一筆生意的流程）

| 階段 | 文件 | 格式（推測） | 依據 |
|---|---|---|---|
| 投標前 | 買方的**材料標準（材規）**／技術規範書：每種設備一份，有版次編號（例：桿上變壓器 C001、亭置式 C035，修訂時在編號後加年月 C035(96-07)） | PDF（Word 轉），幾十頁，章節編號、試驗項目表、保證值表 | 查到的：監察院 103 年糾正案文（cybsbox.cy.gov.tw/…/39220） |
| 投標前 | **承製能力審查**文件、合格廠商名單登記 | Word／PDF 申請書 + 附件（ISO 證書、設備清單、過去實績） | 查到的（同上） |
| 投標 | **投標文件**：規格對照表、**保證值**（無負載損、85℃ 負載損）、報價單、型錄 | Word／Excel／PDF；型錄是排版 PDF | 查到的：保證值與減價驗收公式在糾正案文裡 |
| 設計 | **認可圖**（送買方核可的圖面）、單線圖、外形圖、銘牌圖 | DWG／DXF、PDF 圖面（**rag-lab 不收圖**，CLAUDE.md） | 查到的：「得標後是否按原認可圖施作」 |
| 設計 | BOM／材料表、計算書（短路、溫升） | Excel、Word | 推測的 |
| 製造 | **中間檢查**紀錄（買方派員到廠：外觀檢查、特性試驗）、製程檢驗表、不合格報告（NCR）、ISO 9001 程序書 | 紙本簽核後**掃描 PDF**（有印章、手寫數字）、Excel 表單 | 查到的（中間檢查）；推測的（表單形式） |
| 出廠 | **品管試驗報告／出廠試驗報告**：絕緣電阻、變壓比、極性、無負載損、負載損、溫升、衝擊電壓 | Excel 填表再印成 PDF；舊的掃描件；**橫式表格** | 查到的：驗收項目與試驗名稱在糾正案文；表單形式推測 |
| 驗收 | 買方驗收紀錄、減價驗收計算（Lwt、Lct 公式） | PDF、Excel | 查到的 |
| 交付 | 操作維護手冊、訓練教材、銘牌 | PDF（排版、含圖）、PPT | 推測的 |
| 售後 | 保養紀錄、故障／事故報告、現場照片 | Excel、Word、手機照片 | 推測的 |
| 標準 | CNS、IEC（60076 變壓器、62271 開關設備）、買方的施工規範（例：地下輸電管路施工規範） | 付費 PDF；施工規範公開 PDF | 查到的：經濟部國營事業管理司有「台電施工規範」頁（抓取被擋 403，要用瀏覽器看） |
| 內部 | 會議紀錄、Email、工程變更單、投標檢討 | Word、Outlook、Excel | 推測的 |

**跟法規公報比，新的東西**：
1. **版本**：材規有版次，一題要問「哪一版」；09 全是單一版本。
2. **數字有容差與保證值**：答案不是一個數字而是「實測 ≤ 保證值」「超過就減價」；10 的尺比不了這個。
3. **單位是物理量**（kVA、W、℃、%Z、kV BIL），單位換算與同義（VA↔kVA）比公報多很多。
4. **表格是主角不是配角**：試驗報告整份就是表，橫式、多層表頭、一格一個量測值；05／08 量過一部分。
5. **掃描＋手寫＋印章**：中間檢查與舊試驗報告；06／09 量過掃描，沒量過手寫數字。
6. **圖面**：rag-lab 不收，但真實場景裡「圖號 → 哪張圖」是常見問題，要在 README 講清楚這條線不做。
7. **跨文件**：規範要求 vs 報告實測 vs 投標保證值，三份對著看；現有實驗全是單文件。

## 3. 對下一個實驗（16）的建議

- **語料**：施工綱要規範第 16 篇 10–15 章 + 施工規範 2–3 份 + 監察／審計案文 3–5 份，約 30 份、全部公開、單檔 <10 MB。這批文件沒有「條」（是 1.1／1.2 的階層編號），正好接 13 的「沒有條的文件怎麼切」。
- **題型**：數字（電壓等級、試驗電壓、最小線徑）、**引用**（這章引了哪些 CNS）、**送審文件清單**（要繳什麼報告）、**版本**（哪一版材規）——後兩種是公報沒有的。
- **先不做**：試驗報告（公開沒有真的）、圖面（不收）。README 第 5 節寫明這兩條是真實場景裡最大的兩塊，這裡沒量到。
- **流程**：照 playbook 六步走一次，六條結論逐條標「成立／翻掉／沒量到」。
